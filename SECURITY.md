# Security policy

This is the default for every public repository of mine that doesn't have its
own `SECURITY.md`.

## Reporting a vulnerability

Please report privately, not in a public issue or pull request: use GitHub's
**Report a vulnerability** button on the Security tab of the repository
(private vulnerability reporting), at
`https://github.com/keasbeexd/<repository>/security/advisories/new`.

For NGM Peon (the Discord bot and ngmpeon.app), whose code isn't public,
report on the NGM Addon's repository:
https://github.com/keasbeexd/nootropic-guild-manager/security/advisories/new

Include what you found, how to reproduce it, and the version or commit you
tested. A proof of concept helps; please test only on your own machine and
your own accounts.

You can expect an acknowledgement within a week. Fixes for confirmed issues
are released as soon as they are ready, with an advisory that credits you
unless you ask not to be named.

## Supported versions

Only the newest release (or, for projects without releases, the newest
commit on the default branch) gets security fixes.
